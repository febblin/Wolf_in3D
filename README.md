# Wolf_in3D — 3D Tech Demo / Game для PSP

**Wolf_in3D** — это демонстрационная 3D-игра, написанная на 100% Java и работающая на Sony PlayStation Portable через рантайм **jdJavaSE**. 

Это доказательство того, что интерпретируемая Java способна выдавать честный 3D-рендер на железе 2004 года.

## 🔥 Особенности

*   **Честный 3D-конвейер:** Трансформация вершин, перспективное деление, отсечение по пирамиде видимости и сортировка по глубине (Painter's algorithm).
*   **Освещение:** Динамический Flat Lambert для каждого треугольника.
*   **Искусственный интеллект:** Враги (октаэдры) используют **Flow Field** (поле направлений) для обхода домов, а не просто летят по прямой.
*   **Физика и коллизии:** AABB-коллизии со скольжением вдоль стен и защитой от застревания.
*   **Эффекты:** Взрывы (расширяющиеся белые октаэдры), вспышки экрана при уроне и выстрелах.
*   **Звук:** Выстрелы, получение урона и Game Over.

## 🎮 Управление

*   **Z (Left Trigger):** Поворот влево
*   **X (Right Trigger):** Поворот вправо
*   **Аналоговый стик:** Движение прицела
*   **Cross (Крест):** Выстрел
*   **Любая кнопка:** Начало игры / Рестарт после Game Over

## 🚀 Установка

1. Убедитесь, что у вас установлен рантайм **jdJavaSE** (см. соответствующий репозиторий).
2. Скачайте архив в разделе **Releases**.
3. Распакуйте содержимое (папку `Wolf_in3D`) в `ms0:/PSP/GAME/`.
4. Структура должна быть такой:


ms0:/PSP/GAME/Wolf_in3D/
├── EBOOT.PBP
├── Wolf_in3D.jar
└── Wi3d_data/audio/*.wav


5. Запускайте и играйте!

## 🛠 Технические детали

Вся математика игры (векторы, матрицы) выполняется через классы `jdjava.math`, которые уходят в нативные вызовы VFPU. Рендер использует `java.awt.Graphics` (метод `fillPolygon`), который в jdJavaSE оптимизирован и батчится для отправки в Graphics Engine консоли.
